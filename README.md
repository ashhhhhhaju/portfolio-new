# Ashwin Aju - Portfolio Website

INFR3120 Assignment 1

## Pages

Four separate HTML pages: index.html (Home), about.html (About Me), projects.html (Projects), contact.html (Contact Me).

## Responsive Design

No Flexbox is used anywhere in this project. The projects grid uses CSS Grid instead.

Three separate CSS files are linked with the media attribute so each one only loads for its screen size:

- css/style.css - laptop and desktop (default, no max-width). Projects show 3 per row.
- css/tablet.css - loads under max-width 1024px, the normal tablet width. Projects show 2 per row.
- css/mobile.css - loads under max-width 600px, phone width. Projects show 1 per row and the nav links stack vertically.

## Gradients

- Standard linear gradient on the Home page welcome section: linear-gradient(to bottom, #028090, #013a40)
- Angled linear gradient on the buttons: linear-gradient(135deg, #028090, #22d7d7)
